# MauiTaskFlow

A simple **.NET MAUI** project created for learning and practicing cross-platform application development with **C# and XAML**.

## 🎯 Purpose

This project is a practical playground for learning .NET MAUI concepts and gradually building a small task management application.

## 🛠️ Technologies

* .NET 10
* C#
* .NET MAUI
* XAML

## 📱 Target Platforms

* Android
* Windows

## 🚧 Project Status

This project is currently under development and is primarily intended for learning and experimentation.
